# ParkVision — список фич для вайрфрейминга

**Назначение документа:** перечень экранов, элементов и состояний, достаточный для того,
чтобы нарисовать вайрфрейм вручную (бумага / Figma / Excalidraw) без обращения к коду.

**Источники:** [CLAUDE.md](../CLAUDE.md) (спека, API-контракты), [Agents.md](../Agents.md) (роли),
[cv-service/README.md](../cv-service/README.md) (что реально умеют камеры на 13.11.2026).

Приоритеты: **P0** — без этого нет демо · **P1** — сильно улучшает демо · **P2** — после хакатона.

---

## 0. Ограничения реальности, которые ломают наивный вайрфрейм

Прочитать до того, как рисовать. Каждый пункт меняет вид экрана.

| # | Факт | Что это значит для UI |
|---|------|-----------------------|
| 1 | **Не все парковки состоят из «мест».** CAM-001 (Багратиона) и CAM-002 (Светланская) — грунт/обочина без разметки, там только **зоны**: полигон + вместимость + счётчик занятых. Дискретные места есть только на CAM-003 (ТЦ Снеговая падь). | Нужны **два разных вида карточки парковки**: «схема с местами» и «зона: N из M свободно». Нельзя рисовать один макет со схемой мест и считать, что он подойдёт всем. |
| 2 | **Статус `unknown` — полноправное третье состояние**, а не ошибка. Возникает при confidence < 0.7, тени, перекрытии, недоступности камеры. | Легенда и маркеры должны иметь **4 цвета**: свободно / занято / неизвестно / нет данных (устарело). Серый нельзя «прятать». |
| 3 | **Данные устаревают за 60 секунд.** Устаревшее место не показывается как `free`. | На каждом экране с данными — **метка времени** («обновлено 12 сек назад») и явное вырождение в «нет данных». |
| 4 | **Это рекомендация, а не бронь.** Одно место может быть предложено нескольким водителям. | Текст-дисклеймер на экране выбора места + обязательный сценарий «место заняли, пока вы ехали → альтернатива». |
| 5 | **Архива у камер нет** (DVR отдаёт 403), история копится только с момента старта рекордера. | Прогноз занятости к моменту прибытия в MVP — **эвристика**, а не ML. Не рисовать графики «занятость по часам»: данных под них нет. |
| 6 | **Камеры публичные, но кадры содержат номера и лица.** Наружу уходят только агрегированные статусы. | В мобильном приложении **нет и не будет живого видео с камеры**. Кадр можно показывать только в админке. |
| 7 | 2ГИС SDK может не дать полноценную навиг��цию. | Запасной вариант экрана маршрута: точка подъезда + схема, без пошаговой навигации. Вайрфреймить оба. |

## 2. Поэкранный список фич

### S0 — Запуск / разрешения · P0
Минимальный экран, но нужен для демо на устройстве.

- Логотип + название, одна строка позиционирования («Свободное место, а не просто парковка»).
- Запрос разрешения на геолокацию с объяснением, зачем.
- Состояние «в разрешении отказано» → приложение работает, но центр карты = центр Владивостока, режим «Ближе к цели» считает от выбранной вручную точки.
- Индикатор загрузки первых данных (`GET /parkings`).

**Рисовать:** 2 состояния — запрос разрешения и отказ.

---

### S1 — Карта (главный экран) · P0
Основной экран, на нём будут смотреть 80% времени демо.

**Элементы:**
- Полноэкранная карта 2ГИС, центр — текущее положение пользователя.
- **Маркеры парковок** с подписью количества свободных мест. Цвет = светофор:
  - 🟢 зелёный — свободных много (> 30% вместимости);
  - 🟡 жёлтый — мало (1–30%);
  - 🔴 красный — свободных нет;
  - ⚪️ серый — данных нет / устарели / камера недоступна.
- Бейдж на маркере: `7/25` (свободно / всего).
- Строка поиска сверху: «Куда едем?» → S2.
- Кнопка «Моё местоположение» (recenter).
- Кнопка/чип текущего режима поиска («Ближе к цели» ⇄ «Быстрее припарковаться») — переключение без ухода с карты · P1.
- Нижняя шторка (collapsed): «Рядом 3 парковки · 12 свободных мест» → тянется вверх в список S4.
- Глобальная метка свежести данных: «Обновлено 14 сек назад», при > 60 сек — «Данные устарели» жёлтым.
- Авто-обновление статусов каждые 15–30 сек · P1 (в вайрфрейме — только индикатор).

**Состояния для отрисовки:**
1. Норма — 3 маркера разных цветов.
2. Загрузка — скелетон шторки, карта уже видна.
3. Все камеры недоступны — все маркеры серые + плашка «Нет связи с камерами, показаны последние известные данные от HH:MM».
4. Нет интернета — баннер сверху.

**Данные:** `GET /parkings`.

---

### S2 — Выбор цели · P0
Куда пользователь в итоге идёт пешком (не где паркуется).

- Поле ввода адреса / названия (подсказки 2ГИС).
- Быстрые варианты: «Текущее местоположение», «Поставить точку на карте».
- Недавние цели · P2.
- Выбранная цель показывается на карте отдельным маркером-флажком, отличным от парковочных.

**Рисовать:** поле с выпадающими подсказками + режим «поставить точку на карте» (перекрестие по центру + кнопка «Готово»).

---

### S3 — Выбор режима поиска · P0
Ключевая фича продукта, из-за неё проект не «ещё одна карта парковок». Должен быть виден, а не спрятан в настро��ках.

Две крупные карточки-кнопки, каждая с пояснением одной строкой:

| Режим | Заголовок | Пояснение под кнопкой |
|-------|-----------|------------------------|
| `closest` | **Ближе к цели** | «Меньше идти пешком. Возможно, дольше ехать и искать» |
| `fastest` | **Быстрее припарковаться** | «Встанете раньше, но до цели придётся пройти» |

- Опционально: слайдер/поле «Я буду через ~N минут» (`arrival_eta_minutes`) · P1 — влияет на риск занятости.
- Фильтр типа места: обычное / для инвалидов / электро · P1.
- Поведение: выбор режима сразу ведёт в S4, повторный выбор доступен из чипа на карте.

**Рисовать:** шторка с двумя карточками + состояние «выбран режим» (подсветка).

---

### S4 — Список рекомендаций · P0
Результат `POST /recommendations`. Шторка поверх карты (не отдельный экран) — чтобы видеть и список, и точки.

**Карточка рекомендации (строка списка):**
- Название парковки + ID места (`S-014`) либо «Зона A» для зонных парковок.
- Статус-пилюля: свободно / неизвестно.
- `🚶 120 м` — пешком до цели.
- `🚗 8 мин` — ехать.
- «Обновлено 12 сек назад».
- Индикатор уверенности · P1: «высокая / средняя уверенность» вместо голого `0.97`.
- Для зон вместо ID места: «4 из 12 свободно» + «конкретное место не гарантируется».
- Кнопка «Поехали».

**Элементы экрана:**
- Заголовок с текущим режимом и возможностью его сменить («Ближе к цели · Изменить»).
- Сортировка уже сделана бэкендом — пользовательской сортировки нет (не усложняем).
- Подсказка-дисклеймер внизу списка: «Это рекомендация, а не бронирование места».

**Состояния:**
1. 3–5 рекомендаций.
2. **Пусто** — «Свободных мест сейчас нет» + предложение: расширить радиус / переключить режим / показать парковки целиком.
3. Только `unknown` — «Точных данных нет, показываем парковки с местами по вместимости».
4. Ошибка запроса → повтор.

---

### S5 — Карточка парковки · P0
Открывается тапом по маркеру. Данные: `GET /parkings/{id}`.

- Название, тип (бесплатная / платная / ограниченная), правила доступа.
- Крупно: `7 свободно · 18 занято · 0 неизвестно` из `25`.
- Полоса-диаграмма заполненности (три цвета).
- Время последнего обновления.
- Кнопка «Показать схему» → S6 (только для парковок с дискретными местами).
- Кнопка «Маршрут до въезда» → S7.
- Блок «Прогноз к вашему прибытию» · P1: «Через 10 минут вероятно 4–6 свободных мест» + явная пометка «оценка по текущей динамике, не гарантия».
- Для зонной парковки блок прогноза и схемы заменяются на «Площадка без разметки — точное место подскажет счётчик занятости».

**Рисовать обязательно 2 варианта:** со схемой (CAM-003) и зонный (CAM-001/002).

---

### S6 — Схема парковки / выбор места · P0

**Вариант A — дискретные места (CAM-003):**
- Схематичный план парковки сверху вниз: прямоугольники мест, подписанные ID.
- Цвета те же 4 статуса.
- Тап по месту → подсветка + нижняя плашка с деталями (`GET /spots/{id}`): ID, статус, уверенность, обновлено, расстояние пешком до цели.
- Кнопка «Еду сюда» → S7.
- Легенда цветов (постоянно видна, не в попапе).
- Место, рекомендованное системой, помечено звёздочкой/рамкой.

**Вариант B — зона:**
- Контур площадки с заливкой и крупной цифрой «≈4 свободных из 12».
- Текст: «Места не размечены, система считает количество машин на площадке».
- Кнопка «Еду сюда» ведёт к точке подъезда зоны.

**Состояния:** место свободно / место занято (кнопка «Еду сюда» заблокирована + «Выбрать другое») / статус неизвестен (кнопка активна, но с предупреждением).

---

### S7 — Маршрут до точки подъезда · P0
Важно: маршрут строится **не до центра парковки**, а до `approach_point` конкретного места/зоны.

- Карта с линией маршрута, точкой подъезда и флажком конечной цели.
- Верхняя плашка: «Место S-014 · ещё свободно · 8 мин».
- **Живой монитор выбранного места:** статус перепроверяется, пока пользователь едет. Три состояния плашки:
  - зелёная — «Место свободно»;
  - жёлтая — «Статус неизвестен, подъезжайте осторожно»;
  - красная — «Место заняли» → S8.
- Нижняя панель: пешая часть маршрута после парковки (`120 м до цели`).
- Кнопка «Отменить».
- Фолбэк без навигации 2ГИС · P0-резер��: вместо пошаговых инструкций — статичная линия + текст «Въезд со стороны ул. N», и схема подъезда картинкой.

---

### S8 — Место заняли → альтернатива · P0
Обязательный пункт критериев приёмки, легко забыть при вайрфрейминге.

- Модальное окно / шторка поверх маршрута: «Место S-014 заняли 30 секунд назад».
- Сразу одна лучшая альтернатива карточкой (тот же формат, что в S4): ID, расстояние, ехать.
- Две кнопки: «Перестроить на S-017» (основная) и «Показать все варианты» → S4.
- Если альтернатив нет: «Свободных мест на этой парковке не осталось» + «Искать рядом».

---

### S9 — Прибытие / завершение · P1
- «Вы на месте. До цели 120 м пешком» + кнопка «Построить пеший маршрут».
- Опрос в одну кнопку: «Место было свободно? Да / Нет» — ценнейший фидбек для оценки точности CV на демо.
- Короткая сводка экономии · P2: «Нашли место за 6 минут».

---

### S10 — Сквозные состояния и системные экраны · P0
Рисуются один раз, переиспользуются.

- Загрузка (скелетоны, не спиннер на весь экран).
- Нет сети.
- Сервер недоступен (`/health` красный).
- Данные устарели (> 60 сек) — жёлтая плашка, статусы перекрашиваются в серый.
- Пустые состояния для списков.
- Снэкбар ошибки с «Повторить».

## 3. Админ-панель (Streamlit) · P1
Отдельный набор вайрфреймов, достаточно блочных схем.

### A1 — Камеры
- Таблица: ID, название, разрешение, статус (active/inactive/error), время последнего кадра, кадров за час.
- Превью последнего кадра.
- Флаг «получена заглушка vladlink» — отдельным красным бейджем, это частый реальный сбой.
- Флаг «картинка зависла» (хеш без overlay-зон не меняется).

### A2 — Разметка ROI
- Кадр камеры, поверх — рисование полигонов.
- Переключатель типа: **место (quad)** / **зона (polygon + capacity)**.
- Список размеченных объектов с ID, удаление/редактирование.
- Панель ошибок валидатора списком: неуникальные ID, вырожденные полигоны, ROI вне кадра, квады < 28 px, координаты вне Владивостока.
- Кнопка «Сохранить в cameras.yml».

### A3 — Мониторинг и статистика
- График занятости по времени (с момента запуска рекордера, не раньше).
- Доля `unknown` по камерам — главный индикатор качества CV.
- Лента последних изменений статусов.
- Сводка по `POST /internal/occupancy`: частота, задержки, ошибки.

## 4. Компоненты, которые нужно нарисовать один раз

| Компонент | Варианты |
|---|---|
| Маркер парковки | зелёный / жёлтый / красный / серый × с бейджем количества |
| Пилюля статуса места | свободно / занято / неизвестно / нет данных |
| Метка свежести | «12 сек назад» / «устарело» |
| Карточка рекомендации | место / зона |
| Полоса заполненности | три сегмента |
| Прямоугольник места на схеме | 4 статуса + «выбрано» + «рекомендовано» |
| Шторка (bottom sheet) | 3 высоты: свёрнута / половина / полная |
| Плашка-монитор места в пути | зелёная / жёлтая / красная |
| Легенда цветов | компактная строка |
| Дисклеймер «не бронь» | одна строка |

## 5. Порядок рисования (если времени мало)

1. **S1 Карта** — без неё нечего показывать.
2. **S3 Режим поиска** — главный отличительный признак продукта.
3. **S4 Рекомендации** (шторка).
4. **S6 Схема, вариант A** — «вот ваше конкретное место».
5. **S7 Маршрут** + **S8 Альтернатива** — закрывают критерий приёмки про перехват места.
6. **S5 Карточка парковки**, оба варианта.
7. **S10 Состояния**.
8. Админка A1–A3 блочно.

Демо-сценарий, который должен пройти по вайрфрейму без разрывов:
**открыл карту → ввёл цель → выбрал «Ближе к цели» → получил место S-014 → поехал → место заняли → получил S-017 → приехал.**

---

## 6. Чего в MVP-вайрфрейме НЕ рисуем

- Авторизацию и профиль пользователя.
- Бронирование и оплату парковки.
- Живое видео с камеры в мобильном приложении (номера и лица).
- Историю поездок, достижения, геймификацию.
- Графики «занятость по дням недели» — исторических данных нет.
- Push-уведомления (P2), маршруты на несколько парковок, карпулинг.
